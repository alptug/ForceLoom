# ForceLoom

ForceLoom is an open-source data analysis library for single-molecule force spectroscopy, with an emphasis on magnetic tweezers. It includes (or will include) modules for (time-series) statistics, optimization, model fitting and instrument calibration.

ForceLoom is built to work with large datasets, possibly exceeding the system memory, and offers high-performance implementations for the algorithms and techniques used in single-molecule force spectroscopy. It includes two interfaces: Rust and Python, where the Python interface is backed by the Rust codebase. It is designed to run on all popular operating systems.

> ForceLoom is in early development stage. Its features are far from complete and breaking changes may occur.
